## 📄 File Descriptions

| File | Description |
|------|-------------|
| **data_type.py** | Demonstrates Python's built-in data types, including strings, integers, floats, complex numbers, dictionaries, booleans, sets, lists, and tuples. |
| **if_statement.py** | Covers conditional statements, nested conditions, logical operators, and the ternary operator using practical examples. |
| **python_for_loop.py** | Demonstrates `for` loops, `range()`, nested loops, star patterns, multiplication tables, factorials, prime numbers, and other practice programs. |
| **while_loop.py** | Covers `while` loops, `break`, `continue`, list traversal, number-based programs, and problem-solving exercises. |
| **python_function.py** | Explains Python functions, parameters, return values, `*args`, `**kwargs`, dictionary unpacking, and practical examples. |
| **python_recursion.py** | Demonstrates recursion through countdowns, factorials, Fibonacci sequences, recursive list operations, and finding the maximum value in a list. |
| **python_decorator.py** | Introduces Python decorators with examples of function wrapping, execution timing, authentication, and decorators with arguments. |
| **python_math_module.py** | Covers Python's `math` module, including square roots, powers, factorials, GCD, LCM, logarithms, trigonometric functions, and mathematical constants. |
| **datetime_module.py** | Demonstrates working with dates and times, formatting, parsing, date arithmetic, and age calculation using Python's `datetime` module. |
| **regular_expression.py** | Covers Python Regular Expressions (`re` module), pattern matching, character classes, quantifiers, validation, and text extraction. |
| **oops.py** | Demonstrates Object-Oriented Programming concepts including classes, objects, constructors, encapsulation, inheritance, and polymorphism. |
| **exception_handling.py** | Covers exception handling using `try`, `except`, `else`, and `finally`, including handling common exceptions. |
| **atm_project.py** | A beginner-friendly ATM simulation project implementing PIN verification, balance inquiry, cash withdrawal, deposit, and basic banking operations. |

## 🚀 How to Run

1. Clone this repository

```bash
git clone https://github.com/your-username/python-basics.git
```

2. Navigate to the repository

```bash
cd python-basics
```

3. Run any Python file

```bash
python filename.py
```

Example:

```bash
python python_function.py
```
